# 복기와 다시 보기

> **2026-10-22 구현**: `/review`. 판 한눈에 보기(주공·공약·프렌드·버린 카드·돈 / 넘긴 카드·점수·문 슛, 처음 패, 턴 표), 다시 보기(게임 화면 + 앞뒤 단추·재생 + 상황판: 모든 패·이 판에 나온 카드). 마이티·하트, 혼자·친구와(방장·참가자, 일반·멘탈 포커) 모두. 코드는 `apps/web/src/review/`, 게임마다 다른 부분은 `GameKit.review`.
> - 저장: IndexedDB `mighty-review`, 최근 50게임, 판이 끝날 때마다 같은 대국을 고쳐 쓴다(그만둔 게임도 끝낸 판까지).
> - 멘탈 포커 판은 판별 실제 패(`deals`, 카드 지도 포함)를 남기고, 다시 돌릴 때 자리 표 행동을 실제 카드로 바꾼다. 참가자는 판 검증(마지막 턴 직전)·게임 끝 검증을 통과할 때마다 남긴다.
> - 상황판(2026-10-22 더함): 다음 수의 실제 수와 고수(실력 2단계)라면 둘 수, 점수(마이티: 여당·야당·남은 점수 카드와 공약 / 하트: 자리별 이번 판 점수), 자리별 떨어진 무늬(선 무늬를 따르지 못한 적이 있다. 마이티·조커는 빼고), 이 판에 나온 카드. 게임마다 다른 계산은 `GameKit.review.situation`·`describe`.
> - 복기 기록 내보내기·가져오기(JSON, 더 나중에 고친 게임만 넣는다).


> 2026-10-21 사용자 요청. **보안 작업(멘탈 포커 실제 대전 연결, 부정 표시, 설명 페이지, 여러 브라우저 대전 점검)이 모두 끝난 뒤에 시작한다.**

## 요청
- 게임이 끝나면 지난 게임을 복기할 수 있게 한다.
- 게임마다 기록을 로컬에 남겨, 나중에 혼자 복기한다.
- 판마다 어떤 카드가 나와 어떻게 됐는지 한눈에 보는 자료가 필요하다.
- 다시 보기(리플레이)도 고려한다. 복기할 때는 상황 파악을 돕는 상황판을 덧붙여도 좋다.

## 이미 있는 것
- 엔진은 결정적이라 `시작 조건 + 행동 기록`만 있으면 `replay`로 어느 순간이든 되살린다(packages/engine/src/replay.ts).
- 혼자 하기는 진행 중인 판을 `SavedMatch`(규칙·시드·기록)로 남긴다. 끝난 게임은 남기지 않는다.
- 온라인 판 끝에 방장이 비밀 값과 기록 전체를 공개한다(`audit` 메시지). 참가자도 같은 기록을 갖는다.
- 멘탈 포커로 한 판은 마지막 턴에 모든 열쇠를 공개하므로, 판마다 실제 패를 안다.

## 남길 것 (게임 하나)
- 규칙 문자열, 자리 이름, 컴퓨터 단계, 날짜, 혼자/온라인
- 시드, 판마다의 실제 패(멘탈 포커면 판마다 연 패), 행동 기록 전체
- 결과(판마다 돈 변화, 최종 돈)
- 저장 위치: IndexedDB(게임 수가 많아질 수 있다). 최근 50게임 정도를 남기고 오래된 것부터 지운다. 내보내기/가져오기(JSON 파일)도 둔다.
- 온라인 게임의 기록에는 남의 패가 들어 있다. 판이 끝난 뒤 모두에게 공개된 정보라 문제는 없지만, 저장 전에 한 줄로 알린다.

## 보여 줄 것
1. **게임 목록**: 날짜, 규칙, 자리, 내 결과. 시작 화면 메뉴에서 들어간다.
2. **판 한눈에 보기(요약표)**
   - 판마다: 주공, 공약, 프렌드(지정 방법과 실제 사람), 버린 카드, 득점, 성패, 돈 변화
   - 턴 표: 행 = 턴(1~10), 열 = 자리. 칸에 낸 카드, 선은 테두리, 이긴 사람은 강조, 점수 카드 수 표시
   - 처음 패 펼쳐 보기(모든 자리)
3. **다시 보기**
   - 게임 화면을 그대로 써서, 기록을 한 걸음씩 앞뒤로 움직인다(처음/이전/다음/끝, 자동 재생 속도)
   - 시점: 내 자리 화면 / 모든 패 공개
4. **상황판** (다시 보기 옆이나 아래)
   - 무늬별로 나온 카드와 남은 카드(마이티·조커·조커콜 표시)
   - 자리별로 드러난 무늬 떨어짐(그 무늬를 못 따른 순간)
   - 여당·야당의 현재 점수, 남은 점수 카드
   - 그 시점에 컴퓨터(고수)가 골랐을 수와 실제 수 비교 — 학습용
5. **하트**도 같은 틀로 만든다(판별 점수, 넘긴 카드, 문 슛).

## 순서
1. 기록 저장(혼자·온라인 공통, IndexedDB)과 게임 목록
2. 판 한눈에 보기 표
3. 다시 보기 조작
4. 상황판
5. 하트
