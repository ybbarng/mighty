# 하트 01. 규칙

하트는 마이티 사이트 안의 숨은 게임이다(`/hearts`). 규칙은 사용자가 대학 때 하던 **윈도우 하트(Microsoft Hearts)** 를 따른다(2026-10-21 사용자 확인). 규칙만 따르고 윈도우 하트의 그림·소리·코드는 쓰지 않는다. 게임 규칙은 저작권 보호 대상이 아니다.

엔진: `packages/hearts-engine` (마이티 엔진과 같은 모양: `createMatch`·`step`·`viewOf`·`replay`).

## 1. 기본 규칙 (윈도우 하트)

| 항목 | 규칙 |
|---|---|
| 인원·카드 | 4명, 52장(조커 없음), 한 사람 13장 |
| 카드 넘기기 | 판마다 3장. 왼쪽 → 오른쪽 → 맞은편 → 안 넘김을 되풀이. 모두 고른 뒤 한꺼번에 넘긴다. 왼쪽은 다음 차례 사람(시계 방향) |
| 첫 턴 | ♣2를 가진 사람이 ♣2로 시작 |
| 따라 내기 | 선 무늬가 있으면 반드시 그 무늬. 없으면 아무 카드나 |
| 첫 턴 제한 | 하트와 ♠Q는 낼 수 없다. 손에 그것뿐이면 예외 |
| 하트 깨기 | 하트가 한 번 나오기 전에는 하트로 선을 잡을 수 없다. 손에 하트뿐이면 예외. ♠Q는 하트를 깨지 않는다 |
| 턴 승자 | 선 무늬에서 가장 높은 카드(A가 가장 높다). 으뜸 무늬는 없다 |
| 점수 | 먹은 하트 1장에 1점, ♠Q 13점. 판마다 합 26점 |
| 문 슛 | 한 사람이 하트 13장과 ♠Q를 모두 먹으면 그 사람은 0점, 다른 사람이 26점씩 |
| 게임 끝 | 누군가 100점 이상이 되면 끝. 점수가 가장 낮은 사람이 이긴다(같으면 함께 이김) |

사용자 기억(2026-10-21): 넘기기 순서 그대로, 문 슛은 아마 다른 사람 +26, ◆J 규칙은 기억에 없음, 100점에서 끝(종이에 손으로 점수를 적었다), 하트 깨기 있음, 첫 턴 점수 카드는 정말 불가피할 때만.

## 2. 옵션 (지역마다 갈리는 것)

| 옵션 | 기본(윈도우) | 다른 값 |
|---|---|---|
| 넘기기 | 돌아가며 | 왼쪽만, 안 넘김 |
| 넘기는 장수 | 3 | 1~4 |
| 문 슛 | 다른 사람 +26 | 내 점수 −26, 없음 |
| 하트 깨기 | 있음 | 없음 |
| ♠Q가 하트를 깸 | 안 깸 | 깸 |
| 첫 턴 점수 카드 | 금지(그것뿐이면 예외) | 허용 |
| ◆J −10 (Omnibus 하트) | 없음 | 있음 |
| 끝 점수 | 100 | 아무 수 |

## 3. 규칙 문자열

`h1-` + 넘기기(c/l/n) + 문 슛(o/s/x) + 하트 깨기(b/x) + ♠Q 깸(q/x) + 첫 턴 점수(f 금지/p 허용) + ◆J(j, 없으면 생략) + 넘기는 장수 + `-` + 끝 점수.

윈도우 하트: `h1-cobxf3-100`. 마이티 규칙 문자열과 겹치지 않는다(마이티 쪽은 15글자 고정이고 `h1-`로 시작하지 않는다).
