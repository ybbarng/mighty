## M4 다듬기

### 연출

- [ ] 섞기·나눠 주기 애니메이션 (지금은 손패만 가운데에서 날아오고, 다른 자리로 가는 카드는 보이지 않는다)
- [ ] 공약 말풍선: 밀린 공약은 흐리게, 당선 발표 띠
- [ ] 효과 글자: 마이티, 조커콜, 프렌드 공개, 런
- [ ] 딜미스 때 선언한 사람의 패를 잠시 공개
- [ ] 키티 3장이 손패로 들어올 때 "새" 표시, 버리기 확정 때 주공 자리로 빨려 들어가기
- [ ] 화면 회전처럼 크게 바뀔 때 이동 대신 흐려졌다 나타나기
- [ ] `prefers-reduced-motion` 대응

### 소리

- [ ] 라이선스를 확인한 효과음 구하기(카드 내기, 마이티, 조커, 조커콜, 공약, 당선, 승리·패배)
- [ ] 소리 켜기/끄기, 음량

### 조작

- [ ] 낼 수 없는 카드를 눌렀을 때 이유 보여 주기 ("♠를 따라 내야 합니다"). 엔진에 거절 사유 함수를 추가한다
- [ ] 키보드: 좌우 화살표로 고르고 Enter로 내기, 패널 숫자 키
- [ ] 터치: 손가락으로 훑어 고르기, 끌어서 내기
- [ ] 속도 설정(느리게/보통/빠르게). 저장소에 `setSpeed`는 이미 있다

### 화면

- [ ] 규칙 세부 설정 화면: 옵션 59개를 진행·공약·카드 효력·딜미스·점수로 묶어 보여 주고, 사용자 규칙으로 저장
- [ ] 점수판·전적 서랍 (엔진의 `records`는 이미 쌓이고 있다)
- [ ] 판 결과의 분석 페이지: 득점·도움·실점·점유율 (엔진의 `history`에 있다)
- [ ] 게임 끝 화면: 최종 등수, 새 게임
- [ ] 이름 바꾸기, 컴퓨터 이름
- [ ] 6·7마(탈락 표시)와 2마(고르기) 화면을 실제로 해 보고 다듬기
- [ ] 개발 모드 표시(왼쪽 아래 N 아이콘) 숨기기: `devIndicators: false`

### 저장

- [ ] 저장/이어하기: `LocalMatch.serialize()`로 브라우저에 저장하고 다시 불러오기
- [ ] 진행 중 새로고침해도 이어지게

### 확인

- [ ] 세로 13장 두 줄 손패를 실제로 확인
- [ ] Playwright 화면 테스트: 한 판 끝까지, 대표 화면 크기별 스크린숏
- [ ] 카드 그림(deck-of-cards) 라이선스 확인, README에 표기
