## M5 컴퓨터 플레이어 2단계

- [x] 보이지 않는 패를 여러 번 추측해 끝까지 둬 보는 봇 (determinized Monte Carlo, `packages/ai/src/search-bot.ts`). 카드 낼 때만 쓰고 공약·교환·프렌드는 1단계 그대로
- [x] 추측할 때 쓰는 정보: 낸 카드, 선 무늬를 못 따라 낸 사람(무늬 떨어짐), 조커콜에 조커를 안 낸 사람. 숨은 프렌드는 추측한 손패에서 프렌드 카드를 가진 사람으로 정한다
- [x] 가벼운 시뮬레이션 경로: 엔진 `step`(매번 깊은 복사) 대신 카드 내기만 하는 상태를 두고 엔진 규칙 함수를 그대로 쓴다
- [x] 세기 비교 `pnpm --filter @mighty/ai bench`: 720판, 같은 판을 자리 바꿔 두 번. 16세계 +0.59, 48세계 +0.94 (판당 돈, 1단계 대비)
- [x] 화면 멈춤: 봇 한 수마다 브라우저에 차례를 넘긴다(`LocalMatch` `pace`). 개발 서버에서 한 판 동안 50ms 넘는 작업이 없어졌다(전에는 최대 약 100ms)
- [ ] (필요해지면) Web Worker로 옮기기. 세계 수를 크게 늘리거나 느린 기기에서 한 수가 50ms를 넘으면
- [ ] 2단계의 공약·키티 교환·프렌드 고르기도 추측 시뮬레이션으로 (지금은 1단계 어림 그대로)
- [ ] 시뮬레이션 속 상대를 1단계 봇보다 덜 뻔하게(무작위 섞기) 해서 2단계끼리 할 때의 세기 확인
- [x] 난이도 선택: 시작 화면·설정에서 보통(1단계)/고수(2단계). 새 게임과 온라인 방의 빈자리부터 적용

- [x] `replay`: 시드와 행동 기록으로 대국 다시 돌리기 (3cd4020)
