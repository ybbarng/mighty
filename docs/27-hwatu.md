# 27. 화투 기초 (2026-10-29)

고스톱·민화투·나이롱뽕이 함께 쓰는 기초다. 2026-10-29 사용자 요청: "화투 관련 기초 UI를 구성해주고, 그걸 활용해서 서브에이전트 3개 돌려서 구현해줘".
게임 셋은 서브에이전트가 워크트리에서 나눠 만들고, 각 게임 문서(28 고스톱, 29 민화투, 30 나이롱뽕)에 적는다.

## 1. 카드 데이터 `@mighty/hwatu`

- 48장 = 12달 × 4장. 카드 번호는 달 두 자리 + 종류 글자다(`g` 광, `a` 열끗, `r` 띠, `p`·`q` 피, `d` 쌍피). 예: `01g` 1월 광, `11d` 11월 쌍피, `09a` 국진.
- 종류
  - 광 5장: 1·3·8·11·12월. 12월은 비광(`special: "rainGwang"`)이다.
  - 열끗 9장: 2·4·8월은 고도리 새(`bird`)다. 9월은 국진(`special: "cup"`)으로, 쌍피로도 쓰는 규칙이 있다.
  - 띠 10장: 홍단 1·2·3월, 청단 6·9·10월, 초단 4·5·7월, 12월 비띠(단 없음).
  - 피 24장: 11·12월에 쌍피가 하나씩 있다(`piValue: 2`).
- 도구
  - `shuffledDeck(seed)`: 같은 시드면 같은 순서다(다시 두기·검증).
  - `sortCards`, `groupByMonth`, `sameMonth`
  - `splitCaptured`: 먹은 패를 종류별로 나누고 피 장수를 센다.
  - `hasAll`
  - 묶음 상수: `HONGDAN`·`CHEONGDAN`·`CHODAN`·`GODORI`
- 점수(고·스톱, 약, 박 등)는 게임마다 다르므로 각 엔진이 정한다.

## 2. 그림과 화면 조각 `apps/web/src/hwatu/components`

- `HwatuCardView`: 직접 그린 단순한 화투(전통 그림을 옮기지 않는다).
  - 달 숫자를 크게 쓰고, 달마다 꽃·나무 그림을 넣는다.
  - 종류 표시
    - 광: 붉은 "光" 배지
    - 띠: 홍단·청단·초단 글씨 띠
    - 열끗: 아래에 이름(고도리 새는 "· 새")
    - 쌍피: "×2"
  - 뒷면은 붉은 무늬다.
  - 고른 카드는 뜨고, 낼 수 없는 카드는 흐리고, 짝 맞는 카드는 테두리로 강조한다.
- `HwatuHand`: 손패. 달 순서로 정리하고, 낼 수 있는 카드만 누를 수 있다.
- `HwatuBacks`: 상대 손패 뒷면(장수만).
- `HwatuFloor`: 바닥. 같은 달끼리 겹쳐 한 묶음으로 보이고, 짝 맞는 카드를 강조한다.
- `HwatuDeck`: 더미와 남은 장수.
- `HwatuCaptured`: 먹은 패를 광·열끗·띠·피로 나눠 겹쳐 보이고 장수를 단다.
- 확인용 화면 `/hwatu-cards`: 48장과 조각 예시다. 게임 목록에는 없다. 화면 시험 `e2e/hwatu-cards.spec.ts`로 확인한다.

## 3. 온라인과 공정성

- 1차: 방장 기기가 시드로 섞는다(오목·장기처럼 방장이 엔진을 돌린다). 판 끝에 기록과 시드를 공개해 참가자가 다시 계산해 확인한다.
- 다음: 멘탈 포커를 화투로 넓힌다. 그러면 방장도 더미와 남의 손패를 모른다.
  - 지금 `packages/fair-play`는 마이티 53장에 맞춰져 있다(`blind.ts`의 자리 표).
  - 48장 일반 덱으로 넓히는 일은 게임 셋을 합친 뒤 한 번에 한다(셋이 동시에 고치면 충돌한다).
- 나이롱뽕의 "뽕" 같은 먼저 외치기는 실시간 판정 조사(docs/31 예정) 결과를 보고 정한다. 1차는 차례로 묻는 방식(응답 창)으로 만든다.
